# PAW-PBE datasets

POTCAR files are covered by the VASP license and are not included. All calculations used the following
PAW-PBE datasets (TITEL line of each POTCAR). Build the POTCAR in the species order of the POSCAR (line 6),
for example with `dft/make_potcar.sh`.
